# Architecture Decision Records

One markdown file per significant decision, named `NNNN-title.md` (e.g.
`0001-use-serper-for-web-search.md`).

Use any clear structure; a good default is:

```markdown
# NNNN. <Title>

Date: YYYY-MM-DD
Status: accepted | superseded by NNNN

## Context
<The forces at play.>

## Decision
<What we chose.>

## Consequences
<What this makes easier, harder, or permanent.>
```

ADRs are immutable history: to change a decision, write a new ADR and mark the
old one superseded.
